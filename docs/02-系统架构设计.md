## 2. 服务拓扑（11 服务）

```
                        ┌────────────┐
   Vue3 SPA ──Ingress──►│  gateway   │  JWT 校验 · 租户解析 · Sentinel 限流 · 灰度
                        └─────┬──────┘
        ┌──────────┬──────────┼──────────┬─────────┬─────────┐
        ▼          ▼          ▼          ▼         ▼         ▼
      auth       org      employee   attendance  recruit  compensation
   认证授权    组织岗位    员工合同     考勤假期     招聘      薪酬
        └──────────┴──────────┬──────────┴─────────┴─────────┘
                              ▼                    ▼
                     flow(Flowable)          performance
                     流程中台               绩效·培训
                              ▼                    ▼
        rag ◄──事件── platform(文件/通知/报表/字典/审计) ──► 全部服务
```

| 服务 | 边界职责 | 数据库 |
|---|---|---|
| hris-gateway | 路由、认证前置、租户解析、限流、审计埋点 | 无 |
| hris-auth | OAuth2.1/OIDC、JWT 签发、RBAC、数据权限规则、租户开通 | auth_db |
| hris-org | 法人/部门树/岗位/职级/编制 | org_db |
| hris-employee | 档案、生命周期(入转调离)、合同、黑名单 | emp_db |
| hris-attendance | 排班、打卡、异常、假期额度与请假 | att_db |
| hris-recruit | 职位需求、渠道、候选人、面试、Offer | rcu_db |
| hris-compensation | 薪资组、薪酬项、社保个税、算薪、工资条、发薪 | cmp_db |
| hris-performance | 考核方案、执行、校准、结果应用；培训计划、课程、学时 | prf_db |
| hris-flow | Flowable 引擎、模型管理、表单绑定、待办中心、流程事件 | flow_db（引擎表+扩展表） |
| hris-rag | 知识空间、文档管线、检索问答会话 | rag_db + Milvus + ES(全文) |
| hris-platform | 文件(MinIO)、通知多渠道、报表、字典、审计日志 | plt_db |

**拆分原则**：一服务一域一库；服务间只走 Feign（同步）+ RocketMQ（事件），禁止跨库 JOIN；
flow 与 rag 为横向能力服务，不被业务表反向依赖。

## 3. 关键调用与事件

同步（Feign）：
- employee/recruit/attendance/cmp/prf → flow：发起流程、查询流程状态、撤回
- 全服务 → auth：权限校验兜底（JWT 自校验为主，auth 仅签发与管理）
- 全服务 → platform：文件、通知；rag → employee/org：人员画像与组织路径（问答个性化）

事件（RocketMQ Topic 约定 `hris-{域}-{事件}`，事务消息+本地消息表）：
- `hris-flow-task-created/completed/timeout` → 待办推送、业务状态回写
- `hris-emp-onboarded` → auth 建账号、platform 发欢迎通知、rag 无需
- `hris-att-month-closed` → compensation 拉取考勤结果集
- `hris-doc-uploaded`（带知识空间标记）→ rag 异步入库管线
- `hris-prf-result-published` → compensation（调薪建议）、通知

## 4. 前端架构

- Monorepo（pnpm + workspace）：`apps/web`（管理端+自助端同一工程，路由分域）、`packages/shared`（请求/权限/组件）。
- 请求层：Axios 封装，统一响应体、traceId 透传、401 静默续期、错误码到文案映射（见 07）。
- 权限：路由级（菜单树接口）+ 按钮级（`v-perm` 指令，权限点编码 `模块:资源:动作`）+ 数据权限后端强制。
- 多租户：登录域/子域名解析租户 → 品牌主题（CSS 变量）可配置。
- 流程设计器：bpmn-js + 自定义 Palette（HR 节点：审批/会签/抄送/表单页签），模型 JSON 存 flow 服务。

## 5. 部署架构（详见 09）

- 生产：K8s 双 AZ，每服务 ≥2 副本，HPA；中间件集群化（Nacos 3 节点、RocketMQ 主从+Controller、MySQL 一主两从+MHA、Redis Cluster、Milvus 集群、ES 3 节点）。
- 本地/联调：Docker Compose 一键拉起全链路（含 Nacos/RocketMQ/MySQL/Redis/MinIO/Milvus/ES）。

## 6. 架构决策记录（ADR 摘要）

| ADR | 决策 | 理由与否选项 |
|---|---|---|
| ADR-001 | 业务域中粒度拆分 11 服务 | 细粒度 16+ 运维复杂度过高；宏服务违背微服务诉求 |
| ADR-002 | Flowable 独立流程中台 | 引擎表隔离、统一治理；否内嵌（表散落）与共享库（隐式耦合反模式） |
| ADR-003 | 租户共享库+tenant_id+分片，头部客户可升独立库 | 成本/密度优先；否独立 Schema（漂移管理难）、否全独立库（运维爆炸），保留升级路径 |
| ADR-004 | Boot 基线 4.0.x 而非 4.1 | SCA 官方适配矩阵锁定 4.0.x，全家桶可用性优先 |
| ADR-005 | RAG 自研（Spring AI Alibaba）+可切换模型供应商 | Java 栈自主可控；否 Dify 集成（多栈、定制受限） |
