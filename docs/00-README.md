# 智云 HR —— 现代化全栈人力资源管理系统 · 需求与设计文档集

> 版本：v1.0（设计基线）　日期：2026-10-14　状态：待评审
> 本阶段交付物为**需求功能点梳理与详细设计文档**，不包含任何代码实现。

## 1. 项目定位

基于 Spring Boot 4 + Spring Cloud 2025.1 + Spring Cloud Alibaba 全家桶、Vue 3 + TypeScript + Ant Design Vue 的
**多租户 SaaS 化人力资源管理系统**，深度集成：

- **Flowable 7.2.x** 工作流引擎（独立流程中台服务，统一审批中心）
- **企业知识库 + RAG 智能问答**（Spring AI Alibaba 自研管线，Milvus 向量库）

规模假设：万人级以上员工、多法人多租户、高可用可容灾部署（Compose 起步、K8s 生产）。

## 3. 术语表

| 术语 | 含义 |
|---|---|
| 租户（Tenant） | 一个独立开通的企业客户，数据完全隔离 |
| 法人主体（Legal Entity） | 租户下的签约公司主体，薪酬/合同归属单位 |
| 编制（Headcount） | 部门岗位的人数配额，入转调离受其管控 |
| BP 流程 | 入职/转正/调岗/离职等员工生命周期审批流 |
| RAG | Retrieval-Augmented Generation，检索增强生成 |
| ACL-aware 检索 | 召回时按用户权限标签过滤知识切片 |
| 待办中心 | 跨模块统一的任务审批工作台 |
| P0/P1/P2 | 需求优先级：必须/重要/可延后 |

## 4. 功能点编号规则

`<模块码>-F-<三位序号>`，如 `ORG-F-001`。模块码：ORG 组织、EMP 员工、ATT 假勤、RCS 招聘、CMP 薪酬、
PRF 绩效培训、FLW 流程、KBD 知识库、PLT 平台、SELF 员工自助、SEC 安全、NFR 非功能。
