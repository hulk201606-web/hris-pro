# 06 数据模型设计

> 范围：全局建模规范 + 各域核心表清单 + 多租户分片与加密策略。字段级 DDL 属实现阶段产物，本文锁定实体、关键列与关系。

## 1. 全局规范

| 项 | 规范 |
|---|---|
| 主键 | BIGINT 雪花 ID（含租户位段），禁自增（分片友好） |
| 公共列 | tenant_id BIGINT NOT NULL、created_by/updated_by、created_at/updated_at DATETIME(3)、deleted TINYINT 逻辑删、version INT 乐观锁 |
| 唯一约束 | 一律 `(tenant_id, xxx)` 复合前缀 |
| 字符集 | utf8mb4_0900_ai_ci；排序敏感字段加 generated column |
| 金额 | DECIMAL(18,4)（薪酬内部计算位），展示层 2 位 |
| 时间 | 存 UTC，展示按租户时区（PLT-F-010）；日期业务字段用 DATE |
| 枚举 | 字典表（PLT-F-007）+ 代码常量，禁魔法数字入注释 |
| 大字段 | > 64KB 走 MinIO 引用，不落 TEXT |

## 2. 分库与分片

- 物理：11 服务逻辑分库；flow_db 独立实例（引擎表）。
- 分片（ShardingSphere-JDBC）：
  - 广播表：字典、配置、职级带。
  - 单片（绑定表组）：员工域 `emp_employment`+`emp_profile_*` 以 tenant_id 哈希分 16 片起步（可倍增，弹性扩容用一致性哈希+数据迁移任务）。
  - 大表二级策略：`att_punch_record` 按 tenant_id 分片 + 时间 RANGE 月分区（保 13 个月热数据）。
  - 头部租户（合同约定制）：`tenant_storage_mode = SHARED | DEDICATED`，DEDICATED 路由到专属数据源（DS per tenant，ShardingSphere 混合分片规则）。

## 4. 跨域关系（ER 主干）

```
auth_tenant 1─N auth_user 1─1 emp_employee
emp_employee 1─N emp_employment N─1 org_dept / org_position / org_grade
emp_employment 1─N emp_contract
emp_lifecycle_case N─1 flow_ext_biz_relation 1─1 ACT_HI_PROCINST
daily_attendance N─1 emp_employment(日期归属版本)
payroll_detail N─1 payroll_run; payroll_run N─1 pay_group N─* emp_employment
leave_request N─1 leave_type; application N─1 job_opening N─1 requisition N─1 org_dept+org_position
qa_message N─1 qa_session; kb_chunk N─1 kb_doc_version N─1 kb_document N─1 kb_space
```

- 不设跨库外键（微服务约束），一致性经事件+对账（04 §7、02 §3）。
- 员工归属一律通过 `emp_employment` 生效区间查询，禁止各域冗余 dept_id 长挂（同步快照仅报表库允许）。

## 5. 敏感数据与加密

| 字段类 | 方式 |
|---|---|
| 证件号/手机号/银行账号/薪酬数字/专项附加 | AES-256-GCM 列级加密（ShardingSphere 加密插件），密钥 KMS 信封，密文列+掩码影子列（`cert_no_mask`） |
| 简历全文/合同附件 | MinIO SSE-KMS |
| 检索内容 | chunk 入 ES/Milvus 前 PII 占位符化（05） |

## 6. 容量估算（万人租户）

emp_employment 版本链 ~5 万行/年；punch_record 300 万行/年（分区）；daily_attendance 250 万/年；
payroll_detail 12 万/年；flow 任务 50 万/年；qa_message 100 万/年。热数据 13 个月，其余归档（对象存储 Parquet + 查询联邦预留）。
