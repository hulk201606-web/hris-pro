# 01 总体需求说明书

> 项目代号：hris-pro（智云 HR）　版本：v1.0　日期：2026-10-14

## 1. 项目背景与目标

企业人力资源管理存在流程审批分散、数据孤岛、制度知识检索低效三大痛点。本项目构建一套
**多租户 SaaS 化人力资源管理系统**，目标：

| 目标 | 度量 |
|---|---|
| 一站式 HR 全模块覆盖 | 组织/员工/假勤/招聘/薪酬/绩效培训/自助 7 大业务域 |
| 审批统一收口 | 全部人事审批经 Flowable 流程中心，平均审批时长下降 50% |
| 制度知识即问即答 | HR 政策/流程类问答首答准确率 ≥ 85%（评测集口径） |
| 万人级多租户 | 单租户万人、平台千租户规模可水平扩展 |

## 2. 角色与用户

| 租户 HR 管理员 | 企业 HR 全权限 | 全模块 |
| HRBP | 按组织范围的业务伙伴 | 员工/招聘/绩效/假勤 |

| 薪酬专员 | 算薪发薪（敏感权限） | 薪酬管理 |

## 3. 范围

### 3.1 范围内（v1.0）

9 大模块（详见 03 分册）：组织管理、员工管理（合同）、假勤管理、招聘管理、薪酬管理、绩效与培训、
流程中心（Flowable）、知识库与智能问答（RAG）、平台支撑（文件/通知/报表/字典/审计）。
另有员工自助门户（跨模块聚合视图，见 03-09 与 02 前端章节）。

### 3.2 范围外（明确不做，留扩展点）

- 社保公积金**申报对接**（仅台账与计算，报盘接口 P2 单独立项）
- 电子签供应商集成（仅预留适配器接口，不自建签章）
- 假勤硬件（考勤机）直连，仅支持标准打卡 API 网关接入
- 财务总账/凭证集成（发薪指令以标准导出+MQ 事件输出）
- 移动端原生 App（Web 自适应 + 企业微信/钉钉工作台 H5 入口 P2）

## 5. 跨模块关键业务流（用例级）

1. **招聘到入职**：职位需求审批(RCS→FLW) → Offer 审批 → 候选人转入职(EMP) → 入职审批流 → 自动开通账号(auth) → 试用到期提醒 → 转正审批。
2. **异动全链路**：调岗/晋升申请 → 审批流 → 生效日期到点自动更新组织归属(ORG)与薪酬项(CMP) → 通知。
3. **考勤到薪酬**：考勤月结(ATT) → 考勤结果集推薪酬(CMP) → 算薪 → 调薪/发薪审批 → 工资条发放 → 发薪指令导出。
4. **知识运营闭环**：制度文件发布(EMP/ATT 审批通过附产物) → 知识入库(KBD) → 员工问答 → 点踩→知识管理员修订→重新索引。

## 6. 主要非功能期望（详见 09）

- 核心查询接口 P95 ≤ 300ms；审批操作 P95 ≤ 500ms；问答首 token ≤ 3s。
- 万人租户早高峰打卡：5,000 TPS 写入不丢不重。
- 租户数据强隔离（行级+分片，SQL 层兜底），越权零容忍。
- 可用性 99.9%；RPO ≤ 5min、RTO ≤ 30min。
