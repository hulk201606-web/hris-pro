  重加密回填 → 终验 38/38 可解密。binlog（log_bin=ON）是本机数据安全的最后防线。

  NoSuchMethodError，KBD E2E 索引重建真实复现）——exclusion 修复；启用 OTLP 导出需统一
  okhttp 版本（OPEN-DECISIONS）。
- **纪律沉淀**：加密 key 一律 .env 注入；迁移执行前后各做 AEAD 抽验；涉密文列 UPDATE
