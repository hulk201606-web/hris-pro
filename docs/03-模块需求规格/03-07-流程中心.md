# 03-07 流程中心（FLW）

> 服务：hris-flow（Flowable 7.2.x 封装）　优先级基调：P0（一期）　被依赖：全部业务域

## 1. 模块概述

统一审批中台：流程建模、部署、实例运行、任务处理、表单绑定、待办中心、流程运营分析。
业务服务经 Feign 发起流程，flow 经 RocketMQ 广播任务与状态事件回写业务。引擎表独立库、租户用 Flowable 原生 tenant 隔离。

## 4. 关键设计约束

- 表单字段值不复制进流程变量（只存引用+摘要变量路由用），防敏感数据进引擎表（尤其薪酬）。
- 任务事件消息带 `flowEventId` 幂等键，业务侧消费必须幂等。
- 引擎历史 level=audit，历史数据归档策略见 06/09。
