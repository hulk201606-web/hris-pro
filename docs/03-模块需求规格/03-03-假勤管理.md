# 03-03 假勤管理（ATT）

> 服务：hris-attendance　优先级基调：P1（打卡/请假链路一期做骨架，二期完整）　依赖：org、flow、platform

## 1. 模块概述

班次排班、打卡采集、考勤计算、异常处理、假期额度与请假加班出差审批、考勤月结输出给薪酬。
计算引擎规则化（租户可配考勤政策），月结结果不可逆（红冲修正走下期调整）。

## 3. 核心实体

AttendanceGroup、Shift、ShiftAssignment、PunchRecord、DailyAttendance、AttendanceException、
LeaveType、LeaveQuota、LeaveQuotaLedger、LeaveRequest、OvertimeRequest、TripRequest、FixPunchRequest、
PayrollCycle、MonthlyClosing、ClosingAdjustment。

## 4. 关键规则

- 请假/加班/出差均以 FLW 审批通过 + 生效日期到点 才计入考勤；跨月按日切片分摊。
- 日考勤计算优先级：法定节假日 > 假期类型 > 排班班次 > 默认政策。
- 月结前置校验：未决异常单 = 0；锁定后仅 ClosingAdjustment 通道可影响下期。
- 年假折算公式与清零规则在假期类型策略内配置，不允许硬编码。
