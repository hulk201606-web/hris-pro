# 03-05 薪酬管理（CMP）

> 服务：hris-compensation　优先级基调：P1（三期，敏感域高权限）　依赖：org、employee、attendance、flow、platform

## 1. 模块概述

薪酬结构定义、按月算薪（考勤/社保/个税联动）、调薪审批、工资条发放与发薪指令输出。
算薪引擎公式化（项=公式树），全程可复算可追溯；数据按"薪酬密域"最高级别保护。

## 3. 核心实体

PayItem（薪酬项+公式版本）、PayGroup（薪资组）、PayGrade（档级）、EmployeePay（定薪明细版本）、
SocialFundProfile、TaxDeduction、PayrollRun（批次）、PayrollDetail、PayrollAdjustment、
PaymentInstruction、Payslip、PeriodLock、ImportBatch。

## 4. 关键规则

- 算薪输入快照化：每次 PayrollRun 固化考勤结果集/定薪版本/参数版本，保证可复算可审计。
- 累计预扣个税依赖跨期间连续账，补发/追溯通过调整项处理不回改历史。
- 任一键算薪/发放动作强制双人复核（计算-审核-发放三段职责分离，系统按角色拦截）。
- 工资条与发薪明细传输全程加密，明文只在受控端渲染。
