# 03-09 平台支撑与员工自助（PLT/SELF）

> 服务：hris-platform　优先级基调：P0（一期内嵌交付）　被依赖：全部服务

## 1. 模块概述

横向支撑能力：文件、通知、报表、数据字典、审计日志；以及跨模块聚合的**员工自助门户**（个人中心、
我的申请、待办入口、工资条、假期余额、证明开具）。

## 4. 关键规则

- 通知模板渲染在 platform 完成，业务服务只发事件+参数（防止模板散落）。
- 审计日志写入走 RocketMQ 异步，但登录/薪酬/导出类为强一致同步落库。
- 员工自助全部接口只允许 `X-Self` 语义（本人数据），聚合视图经各域只读 API，不在前端拼权限。
