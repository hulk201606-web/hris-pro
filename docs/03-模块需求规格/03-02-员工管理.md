# 03-02 员工管理（EMP）

> 服务：hris-employee　优先级基调：P0　依赖：org、flow、auth、platform（文件/通知）、rag（入职知识推送可选）

## 1. 模块概述

员工全生命周期：候选转入职 → 试用 → 转正 → 调动/晋升 → 离职，含档案、合同、黑名单。
所有生命周期动作由 FLW 审批流驱动，审批通过即生成"待生效事务"，到生效日期由调度自动落账。

## 3. 核心实体

Employee（主档）、Employment（雇佣关系，法人×部门×岗位×职级）、EmployeeProfile（分域扩展：education/work/history/family/emergency）、
Contract、ContractTerm、Regularization、Transfer、Termination、BlackList、PendingEffectTransaction（待生效事务队列）、EmployeeStatusLog。

## 4. 员工状态机（关键约束）

```
待入职 ──入职生效──► 试用 ──转正通过──► 在职 ──离职流程通过──► 离职中 ──最后工作日──► 已离职
  │                  │                    │  ▲                    │
  └─取消入职─► 已取消 └─不通过─► 离职中     └──┴─ 调动/晋升(状态不变,事务生效)   退休/黑名单为终态标记
```

- 调动生效与离职互斥：存在生效日期重叠的待生效事务时拦截（按事务队列串行化）。
- 所有终态触发 `hris-emp-status-changed` 事件供 auth/att/cmp 联动。
