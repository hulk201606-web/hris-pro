# 03-06 绩效与培训（PRF）

> 服务：hris-performance　优先级基调：P1（三期）　依赖：org、employee、flow、platform、rag（学习内容检索）

## 1. 模块概述

绩效考核全流程（方案→目标制定→评估→校准→面谈→结果应用）与培训管理（计划、课程、学员、学时台账）。
考核模式支持 KPI 与 OKR 双轨，结果用于调薪建议（CMP）、人才盘点输入。

## 3. 核心实体

Plan（考核方案）、Cycle（考核期）、Goal/KpiItem/OkrObjective、EvalTask、Evaluation、ForcedRule、
CalibrationSession、Appeal、TrainPlan、Course、Instructor、ClassSession、Enrollment、CreditLedger。

## 4. 关键规则

- 考核任务全部超时提醒+可升级（上级上级），逾期默认处理策略按方案配置（自动提交/顺延）。
- 强制分布在部门人数 < 5 时允许豁免合并计算，避免小团队失真。
- 结果"已公布"后不可再改，任何修订走申诉流闭环。
- 评价人对被评人的过程分数互相不可见，仅 HRBP/校准环节可见（防博弈）。
