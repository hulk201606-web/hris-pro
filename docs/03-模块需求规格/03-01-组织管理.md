# 03-01 组织管理（ORG）

> 服务：hris-org　优先级基调：P0　依赖：auth（权限）、flow（组织调整审批）

## 1. 模块概述

维护租户的多法人主体、部门树、岗位/职位/职级体系与编制配额，是员工、假勤、薪酬等所有域的归属基准。
组织变更一律走版本化生效（日期生效），历史可回溯。

## 3. 核心实体（字段级见 06）

法人主体 LegalEntity、部门 Dept（树，path 物化路径）、岗位 Position、职位 Job、职级 Grade、
职级带 GradeBand、编制 Headcount、编制占用 HCOccupancy、组织版本 OrgVersion。

## 4. 关键规则

- 部门树深度 ≤ 8；单租户部门 ≤ 20,000。
- 员工必须且只能有一个"当前生效"部门归属；多部门汇报线用虚拟组织表达。
- 组织历史版本不可物理修改，只允许追加新版本（审计要求）。
- 汇报线解析规则：直属上级 → 部门负责人 → 上级部门负责人，供 FLW 审批人动态计算。
