# 03-04 招聘管理（RCS）

> 服务：hris-recruit　优先级基调：P1（二期）　依赖：org（编制）、flow、employee（转化）、rag（职位 JD 问答）

## 1. 模块概述

从职位需求申请到候选人入职转化的全流程：需求审批、渠道发布、简历获取与解析、
结构化面试、Offer 审批、转正前衔接。简历经授权采集，解析后入库并进入人才库沉淀。

## 3. 核心实体

Requisition（需求单）、JobOpening（招聘职位）、Channel、Candidate、Resume、ResumeParse、
PipelineStage、Application（投递-职位关系）、Interview、InterviewEval、Offer、TalentPool、RecruitLabel。

## 4. 关键规则

- 需求单人数 ≤ 编制缺口；超编需走超编审批分支（DMN 路由）。
- Offer 定薪超出职级带宽上限 10% 时强制加签薪酬委员会节点。
- 候选人拒绝/过期 Offer 自动回流水线"淘汰（Offer 未接受）"阶段并通知需求部门。
- 入职转化后候选人档案只读关联到 Employee，保留招聘溯源链。
