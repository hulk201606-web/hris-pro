# 08 安全与多租户设计

> 范围：认证授权、租户隔离、数据权限、敏感操作、审计合规、接口安全。万人级多租户下"越权零容忍"为最高设计约束。

## 1. 认证（auth 服务 = Spring Authorization Server）

| 项 | 设计 |
|---|---|
| 协议 | OAuth 2.1 + OIDC，授权码 + PKCE 为主流程；企业内部 SSO（企微/钉钉/AD FS）经适配器 |
| Token | Access JWT（RS256，15min，claims：sub、tenant_id、emp_id、roles digest、scope）；Refresh（Rotation + 重用检测撤族） |
| MFA | TOTP 可选启用（租户策略），薪酬/导出/权限变更类操作强制二次认证（独立短票据 60s，一次性） |
| 会话 | 网关+Redis 黑名单（登出/禁用即时失效）；账号禁用事件联动 EMP 离职 |
| 密码 | Argon2id，强度与泄露口令库校验（企业对接期一次性导入检测） |

## 2. 授权模型

- **RBAC**：角色→权限点（`模块:资源:动作`）→菜单/按钮/API 三处同源校验（前端隐藏仅为体验，后端强制）。
- **数据权限**：auth_data_scope 规则（SELF/DEPT/DEPT_SUB/CUSTOM/ALL）在 MyBatis-Plus 拦截器统一注入
  （按表登记维度列 dept_id/emp_id），业务代码不手写范围条件；规则引擎缓存 Redis。
- **字段权限**：档案分组（学历/家庭/证件）与薪酬数字为独立 perm code，DTO 序列化层裁剪（Jackson Filter），
  密域角色白名单（CMP-F-019）。
- **职责分离**：薪酬计算者≠审核者≠发放者（03-05 规则）系统级拦截；超管不可自授薪酬密域。
- 内置角色模板：租户开通即装（HR 管理员/HRBP/部门经理/薪酬专员/招聘专员/员工/审计员/知识管理员），可自定义派生。

## 3. 多租户隔离（纵深四层）

```
① 网关层: JWT.tenant_id → 请求上下文(TTL/Reactor Context 透传)，body/header 中租户字段一律丢弃
② 服务层: 内部 Feign 透传签名头( HMAC 服务间签名)，禁匿名内部接口
③ ORM 层: MyBatis-Plus TenantLineInnerInterceptor 自动注入 tenant_id 条件(全局兜底, 忘写也拦截)
④ 存储层: ShardingSphere 租户分片路由(06); DEDICATED 头部租户独立数据源
```

- Milvus：Collection per tenant 物理隔离（05）；ES 索引租户路由 + routing 强制。
- Redis：key 前缀 `t{tenantId}:`，对象存储桶路径 `tenant-{id}/`。
- 逃生舱审计：绕过租户拦截器的 SQL（如跨租户运营统计）必须显式 `@IgnoreTenant` 注解 + CodeReview 清单 + 运行时告警。

## 4. 敏感操作与数据安全

| 场景 | 控制 |
|---|---|
| 薪酬/身份证/银行卡访问 | 密域角色 + 二次认证 + 每次留审计（谁看了谁的工资） |
| 数据导出 | 审批流（EMP-F-026）+ 水印 + 行数字段上限 + 导出记录 |
| 列级加密 | 06 §5（KMS 信封，密钥轮换年度，密文不可检索，检索走掩码/影子列） |
| 传输 | 全链路 TLS1.2+；服务间 mTLS（K8s Mesh 或证书轮换） |
| 备份 | 加密备份，恢复演练季度一次（09 DR 联动） |
| AI 侧 | Prompt 注入防护（知识内容不执行指令化文本、工具白名单）；问答日志保留脱敏样本供安全审计；模型供应商数据协议合规（不用于训练条款） |

## 5. 审计与合规

- audit_log 只追加（无 UPDATE/DELETE 权限的 DB 账号写入），12 个月在线 + 归档 3 年。
- 覆盖：登录、权限变更、审批动作、敏感查看/导出、租户配置变更、流程干预（04 FLW-F-015）、`@IgnoreTenant` 使用。
- 合规基线：《个人信息保护法》（候选人/员工数据最小化、保留期限、删除响应 RCS-F-022）、等保三级部署基线（09 §可用性章节的安全扩展项）。

## 6. 接口安全

- 网关：Sentinel 限流（IP/用户/租户三维度）、CSP/CORS 白名单、请求体大小、SQLi/XSS 参数模式拦截（防御纵深，非唯一防线）。
- 内部：Feign 双向签名头（时间戳+nonce 防重放 5min 窗口）。
- 开放 API：租户 API Key + HMAC-SHA256 签名 + scope 化端点 + 独立限流桶。
- 越权测试矩阵（每迭代必跑）：水平越权（同角色跨员工/跨部门数据）、垂直越权（低角色打高权限端点）、
  跨租户探测（篡改 tenant 参数/头）、内部路径外打（/internal/** 经公网）。
